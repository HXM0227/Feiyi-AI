# T5 策略工程基线

这组样例用于验证 T5 的确定性规则选择，不代表跨文化表达质量已经通过专家或目标受众验收。

当前覆盖：

- `zh-CN`、`en` 及已支持的语言别名；
- 五种年龄档、四种知识水平、四种表达风格；
- 全球与指定地区两类处理；
- 风险词语言隔离、重复调用稳定性；
- T5 不复制 query、citation、检索片段、图谱哨兵或具体地区值。

在 `t5/` 目录运行：

```powershell
python evaluation/run_baseline.py
```

成功时退出码为 `0`，并输出 JSON 结果。人工评审仍需另行邀请了解目标文化语境的评审者，重点检查准确性、可理解性、刻板印象风险和语气适配。
